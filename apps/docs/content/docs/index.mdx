Onyx is a full-stack SaaS starter kit on Cloudflare, built by
[jxd.dev](https://jxd.dev). Everything deploys as a single Worker: the web
app, the public API, background jobs, scheduled tasks, realtime
collaboration, and the AI assistant.

## How the repository is organized

The monorepo is driven by Vite+ (`vp`) and pnpm workspaces:

- `apps/*` are deployable applications. `apps/web` is the primary Worker.
- `private/*` are focused internal packages, each owning one concern (auth,
  database, storage, mail, and so on).
- `published/*` are versioned packages released to npm: the typed API client,
  the `onyx` CLI, and the Vite plugin.
