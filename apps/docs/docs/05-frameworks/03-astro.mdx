---
title: Astro
description: Pass the Vite plugin through vite.plugins and prerender collection entries with getStaticPaths.
icon: rocket
---

Astro builds on Vite, so the [plugin](/reference/codegen) works unchanged:
passed through `vite.plugins`, it writes `src/stet.gen.ts` before every build
and dev-server start, and keeps watching while the dev server runs, so a field
added in the Stet UI reaches your types a few seconds later.

You need an organization API key in `STET_API_KEY`; the
[quickstart](/quickstart) covers creating one.

<Steps>

<Step title="Install">

```package-install
@stetcms/vite @stetcms/client @astrojs/node
```

The adapter earns its place in step 2.

</Step>

<Step title="Add the plugin">

```ts astro.config.ts
import node from '@astrojs/node';
import { stet } from '@stetcms/vite';
import { defineConfig } from 'astro/config';

export default defineConfig({
  output: 'server',
  adapter: node({ mode: 'standalone' }),
  vite: {
    plugins: [stet()],
  },
});
```

</Step>

<Step title="Read content in frontmatter">

Frontmatter runs on the server, so the API key never reaches the browser:

```astro src/pages/blog/index.astro
---
import { stet } from '../../stet.gen';

const posts = await stet.posts.list();
---

<ul>
  {posts.map((post) => <li>{post.title}</li>)}
</ul>
```

Commit `src/stet.gen.ts`: it contains no secrets, and the project type-checks
without a key or a reachable Stet, because the plugin
[never fails a build](/reference/codegen) over either.

</Step>

<Step title="Prerender content routes">

Set fixed pages to prerender and return every collection slug from
`getStaticPaths`:

```astro src/pages/blog/[slug].astro
---
import { stet } from '../../stet.gen';

export const prerender = true;

export async function getStaticPaths() {
  const posts = await stet.posts.list();
  return posts.map((post) => ({ params: { slug: post.slug }, props: { post } }));
}

const { post } = Astro.props;
---

<h1>{post.title}</h1>
```

Astro now writes one HTML page per post during `astro build`. If Stet is
unavailable while a key is configured, the build fails.

</Step>

</Steps>

The
[Astro example](https://github.com/jamiedavenport/stet/tree/main/examples/astro)
is this guide as a running app, wired to a seeded local Stet.
